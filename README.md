# DSP
Digital Systems Project

The mobile app is developed using Flutter and Dart as the programming language. 

The app is launched on an IOS simulator.

All tests were done as a black-box test where the app was launched from the perspective of end-users and the functionalities were validated then.

Only the code files were uploaded to this github repository as they contain all the components of the app that I did. Other folders that contain files about the IOS and Android simulators were not added in this repository because they were already included when downloading FLutter.
